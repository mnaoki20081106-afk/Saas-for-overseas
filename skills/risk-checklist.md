# 提出前のセルフチェック（鉄のルール第4条）

成果物を上（英世・一葉→諭吉、諭吉→オーナー）に出すときは、
**必ず自分でリスクを洗い出して、セットで報告します。**

「良いことだけ書いて出す」を禁止します。

## 毎回書く3つ

| 項目 | 問い |
| --- | --- |
| **潜むリスク** | これをやると何が起きうるか |
| **自信のない点** | どこが推測で、どこが確認済みか |
| **こうなったら失敗** | 何が起きたら「間違いだった」と分かるか |

## リスクの探し方（この順で自問する）

### 1. お金のリスク
- [ ] 報酬条件は公式ページで確認したか。推測が混ざっていないか
- [ ] 「毎月入る」と書いたが、本当に recurring か。一度きりではないか
- [ ] Cookie期間は短くないか（30日以下なら要注意）
- [ ] 審査に通らない可能性はどれくらいか

### 2. 規約のリスク
- [ ] 裏付けのない最上級表現（the best / #1 / guaranteed）を書いていないか
- [ ] アフィリエイト開示は入っているか。二重になっていないか
- [ ] 効果を約束する表現になっていないか

### 3. アカウント停止のリスク（★最重要）
- [ ] 同じ文案のピンを繰り返していないか
- [ ] 1日の投稿数が上限を超えていないか
- [ ] 同じ記事にピンを集中させすぎていないか

**Pinterest のアカウントが止まると、集客手段が丸ごと消えます。**
この事業でいちばん怖い事故です。

### 4. 検索のリスク
- [ ] 既存記事とキーワードが被っていないか（自分の記事同士で食い合う）
- [ ] 見出しの構成が既存記事と似すぎていないか
- [ ] 年号や「最新」を書いて、記事を古びさせていないか

### 5. 判断のリスク
- [ ] データがないのに「効きそう」と書いていないか
- [ ] 母数が足りているか（ピン20枚 / 成約3件）
- [ ] 1回に2つ以上の変数を変えていないか

### 6. 時間のリスク
- [ ] これは本当に今やるべきことか
- [ ] 詰まっている場所（リンク0件・Pinterest審査）を迂回していないか

## 書き方の例

```
【リスク】
・Cookie期間が30日と短めです。読者が比較検討に時間をかけると、報酬になりません。
・この案件の審査難易度を3/10と見積もりましたが、これは公式ページに
  「誰でも参加できます」と書いてあることからの推測で、実際に応募していません。
・Pinterestがまだ Trial access なので、投稿しても本人にしか見えません。
  つまりこの記事は当面、集客ゼロのまま置かれることになります。

【こうなったら失敗】
・応募して2週間以内に審査結果が来なければ、この案件の見立ては外れです。
・記事公開から3ヶ月でピンの表示数が100を超えなければ、切り口が読者に
  刺さっていないと判断します。
```

**オーナーに指摘される前に、自分で言う。** それがこの会社の信用です。
