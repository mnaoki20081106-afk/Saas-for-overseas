# データがない最初の3ヶ月の振る舞い（全員必読）

## 原則

**実測データのあるピンが20枚に満たないあいだは、「どれが良いか」を判断してはいけません。**

判断できるだけの材料がないからです。この時期にやることは最適化ではなく、
**データを作ること** です。

## なぜこれが重要か

根拠がないのに「この切り口が効きそうです」と書くと、それは **捏造** です。
そして後から「何が効いたのか」を永久に追えなくなります。

一度そうなると、その後どれだけデータを貯めても、
最初の判断が混ざっているせいで正しい学習ができません。

## この期間の具体的な振る舞い

| 変数 | やること |
| --- | --- |
| 記事の型（4種） | comparison → alternatives → best-for-pain → deep-review を **順番に回す** |
| ピンのテンプレート（5種） | 1記事で **全部使う** |
| ピンの切り口（10種） | 1記事で **全部使う** |
| 配色（8種） | `co` が自動で順番に割り当てる。指定しない |
| 投稿時刻 | 既存の設定を均等に使う |

**1回に1変数だけ変える**、が実験の原則です。
テンプレも配色も切り口も同時に変えたピンは、何が効いたのか永久に分かりません。

## 書き方

企画の `basedOn` には、正直にこう書きます。

```json
"basedOn": [{
  "signal": "まだ実績データがありません。記事タイプを一巡させてデータを作る段階です。",
  "source": "data/kpis.json",
  "confidence": "low",
  "sampleSize": 0
}]
```

オーナーへの承認カードには、必ずこう書きます。

> **まだ根拠となるデータがありません。データを作るための1本です。**

## 「数字が動かない」のは正常です

Pinterest は投稿から流入が立ち上がるまで **2〜3ヶ月** かかります。

- この期間、表示数もクリックも増えないのが普通です
- **ここで設定をいじると、学習が壊れます**
- 「効いていないから変えよう」と言い出すのは、いちばんやってはいけないことです

## いつ判断してよくなるか

| 条件 | 判定できるようになるもの |
| --- | --- |
| 300表示以上のピンが **20枚** | どのテンプレート・切り口が効くか |
| 成約が **3件** 以上ある案件 | その案件を続けるべきか |
| 両群に10枚ずつ + 相対差30%以上 | 実験の結論 |

この条件は `config/limits.json` の `coldStart` に書いてあり、
`co status` が「コールドスタート中かどうか」を毎回教えてくれます。

**自分で判断せず、`co status` の表示に従ってください。**
