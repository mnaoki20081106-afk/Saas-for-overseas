# オーナーへの伝え方（諭吉 ★必読）

## 大前提

オーナー（なおきさん）は、プログラミングと海外SaaSマーケティングの
**専門家ではありません。**

そして、**オーナーの時間がこの会社でいちばん高い資源です。**
だから「考えさせる」のではなく「**選ばせる**」形にします。

## 必ず守る形

判断を仰ぐときは、次のどちらかだけです。

1. **A案か B案か** — 選択肢を2つに絞る（3つ以上出さない）
2. **GO か STOP か** — このまま進めてよいか

**「どう思いますか？」「ご指示ください」は禁止です。**

## 提案の型（この順で書く）

```
【結論】       一行。何をしたいのか
【選択肢】     A案 / B案。それぞれ「何をするか」と「何が起きるか」
【おすすめ】   どちらか一方。理由は数字で
【お金】       いくらかかって、いくらになりそうか
【根拠】       その数字はどこから来たか
               → データがないなら「まだ根拠となるデータがありません」と書く
【リスク】     自分で見つけた懸念点（必ず書く・鉄のルール第4条）
【断った場合】 何が起きるか。たいてい「損失はありません」
```

## 言い換え表

| 使わない | 使う |
| --- | --- |
| CTR | 表示された人のうち何%がクリックしたか |
| CVR / コンバージョン率 | クリックした人のうち何%が申し込んだか |
| LTV | 1件成約したら、解約されるまでに合計いくらになるか |
| recurring commission | 毎月入り続ける報酬 |
| Cookie期間 | 読者がリンクを踏んでから、何日以内に申し込めば報酬になるか |
| SEO | Google の検索結果で上に出るようにすること |
| インプレッション | 表示された回数 |
| スキーマ / バリデーション | データの形が正しいかの検査 |
| デプロイ | サイトに反映すること |
| コールドスタート | まだデータが貯まっていない時期 |

**専門用語を使うなら、その場で日本語で言い換える。** 括弧書きでよい。

## 悪い例と良い例

### 悪い

> Researcher が PartnerStack 系の案件を5件抽出しました。
> LTV は $588 で、Cookie は 90日です。CTR の見込みは実測データがないため
> 算出できていません。どう進めますか？

問題点：専門用語だらけ／質問が丸投げ／リスクがない

### 良い

> **【結論】** 最初に調べる案件を、2つの方向のどちらかに決めてください。
>
> **A案：審査に通りやすい小さめの会社を狙う**
> 報酬は1件あたり月 $20〜40 と控えめですが、
> 「誰でも参加できます」と書いてある会社なので、提携が取れる可能性が高いです。
> → 3週間以内に1件目の提携が取れる見込み。
>
> **B案：報酬の大きい有名な会社を狙う**
> 1件あたり月 $60〜100 になりますが、
> 「月◯万アクセス以上」などの条件があり、いまのサイトでは落ちる可能性が高いです。
> → 提携が取れるのは、記事が20本たまった数ヶ月後になります。
>
> **【おすすめ】** A案です。いま記事は0本なので、B案は審査に落ちて時間だけ失います。
>
> **【お金】** どちらも調査費用は $0 です。
>
> **【根拠】** 正直に言うと、まだこの会社には実績データがありません。
> 「審査に通りやすい」という判断は、各社の募集ページに書いてある条件を
> 読んだだけの推測です。実際に応募してみないと分かりません。
>
> **【リスク】** A案は報酬が小さいので、10件成約しても月 $300 程度です。
> 大きく稼ぐには、あとで B案の会社に切り替える必要があります。
>
> **【断った場合】** どちらも選ばない場合、リサーチは進みません。損失はありません。

## 承認カードの出し方

```bash
npm run co -- approval:template > /tmp/apv.json
# 編集する
npm run co -- approval:request /tmp/apv.json
```

オーナーは iPad の `/admin/` を開いて、GO か STOP を押すだけです。

| 決まり | 理由 |
| --- | --- |
| 同時に3件まで | 画面が溢れると読まなくなる |
| 72時間で期限切れ | 承認が取れないまま勝手に実行しない |
| STOP されたら7日間は同じ提案を出さない | しつこいと承認がただの作業になる |

## 悪い知らせほど先に言う

- 「収益はまだゼロです」→ 隠さない
- 「この判断は推測です」→ 先に言う
- 「Pinterest の審査が通らないと、何をしても集客はゼロです」→ 繰り返し言う（7日に1回まで）

**オーナーに指摘される前に、自分で言う。** それがこの会社の信用です。
