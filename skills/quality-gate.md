# 品質ゲートと自己検品（ケン ★必読）

## 2段構えになっています

| 段 | 誰が | 何を見るか |
| --- | --- | --- |
| ① 機械の検査 | `co writer:check` | 語数・H1の数・H2の数と重複・比較表・リンク数・禁止表現・西暦・感嘆符・重複コンテンツ |
| ② 人の検査 | あなた（セルフ検品） | 読み物として自然か・事実が出典と合っているか |

**①は人格と無関係に効きます。**②があなたの弱点なので、手順で縛ります。

## ① 機械の検査

```bash
npm run co -- writer:check <slug>
```

落ちたら、表示された指摘を直して、もう一度実行します。
**全部通るまで提出できません。**

## ② セルフ検品（★手順を守ること）

**自分が書いた文章を自分で検品すると、無意識に擁護してしまいます。**
旧構成では別人格（Editor）が見ていましたが、3層構造ではあなたが見ます。
だから手順で縛ります。

```
1. 書き終えたら、いったん別の作業をする
   → 書いた直後の頭のまま検品しない

2. co editor:context <slug> を実行する
   → 本文だけが表示される。企画の意図は表示されない
   → 「なぜこう書いたか」を思い出さずに読むための仕掛け

3. SaaSを探している英語圏の実務者として、通しで読む

4. ★必ず答える
   「途中で読むのをやめたくなった段落」を1つ挙げ、理由を書く
   ・挙げられないなら「なし」
   ・挙げたら、その段落だけ書き直す

5. co qa:check <slug> で事実とリンクを照合する
   ・料金の記述は、案件の evidence にあるURLを実際に開いて突き合わせる
   ・「たぶん大丈夫」で通さない

6. co editor:submit <file> で提出する
```

**4 を「なし」で埋めるのは楽ですが、それでは検品の意味がありません。**

## チェック項目

| 項目 | 見るもの |
| --- | --- |
| `literal_translation` | 日本語直訳的な英文になっていないか |
| `unnatural_phrasing` | 不自然な言い回し・コロケーション |
| `grammar` | 文法 |
| `vocabulary` | AIっぽい語彙の多用 |
| `us_english` | US英語で統一されているか（colour/color の混在） |
| `overclaim` | 裏付けのない最上級・断定 |
| `repetition` | 同じ主張の繰り返し |
| `logic` | 論理の飛躍 |
| `readability` | 段落と文の長さ・見出しと中身のずれ |
| `search_intent` | 読者が知りたいことに答えているか |

## 判定

| 判定 | 意味 | そのあと |
| --- | --- | --- |
| `pass` | 公開してよい | `content/articles/` へ昇格。**ただし実際の公開はオーナーのGO後** |
| `fix` | 直せば公開してよい | 直した本文を保存してから提出 |
| `reject` | 作り直したほうが早い | 最初から |
| `needs_human` | 判断がつかない | 諭吉に戻す |

往復は **2回まで**。3回目は自動的に `needs_human` になります。
**無理に通そうとしないでください。** 迷ったら `needs_human` にしてください。

## 指摘の書き方

`quote` には**該当箇所をそのまま引用**します。省略しないでください。
引用がないと、後から「本当にそう書いてあったか」を確認できません。

```json
{
  "category": "overclaim",
  "severity": "major",
  "quote": "Acme is hands down the best helpdesk you can buy.",
  "problem": "裏付けのない最上級。アフィリエイト規約で禁止されていることが多い。",
  "suggestion": "「10人未満のサポートチームで、主にメール対応をする場合は」という条件を付ける。",
  "fixed": true
}
```

## このあと諭吉が読みます

あなたの検品が終わっても、**諭吉がオーナーに出す前に独立して読みます。**
あなたは本文を書いた人なので、どうしても見えない部分があるという前提です。

諭吉から指摘が来たら、擁護せずに直してください。
